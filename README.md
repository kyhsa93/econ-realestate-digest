# 경제·부동산 데일리 다이제스트

경제·부동산 뉴스와 서울 아파트 실거래가, 예적금·대출 금리를 매일 모아 보여주는 정적 사이트.
GitHub Actions로 갱신하고 GitHub Pages로 배포한다.

사이트: https://kyhsa93.github.io/econ-realestate-digest/

## 기능

| 페이지 | 볼 수 있는 것 |
|---|---|
| 다이제스트 | 그날의 뉴스·시장 지표·부동산 시세 한 화면. AI 요약(한/영). `?date=`로 지난 기록 |
| 뉴스 | 경제·부동산 기사 목록과 분야별 페이지. 카테고리 필터·검색 |
| 아파트 시세 | 서울 25개 자치구 매매·전세·월세 평당가와 84㎡ 환산가, 전주 대비 증감 |
| 실거래 검색 | 신고된 거래를 지역·금액·면적·연식·단지명으로 찾기 (매매·전세·월세) |
| 금리 비교 | 정기예금·적금·주택담보대출·전세자금대출 금리와 세후 이자 |

## 데이터

| 무엇 | 출처 | 갱신 |
|---|---|---|
| 뉴스 | 경제지 RSS | 하루 4회 |
| 아파트 실거래 | 국토교통부 매매·전월세 실거래가 (서울 25개 자치구) | **주 1회(금요일)** |
| 예적금·대출 금리 | 금융감독원 금융상품통합비교공시 | 하루 1회 |
| 시장 지표 | 코스피·원달러 환율·한국은행 기준금리 | 하루 1회 |
| AI 요약 | 위 뉴스를 Ollama(qwen3:14b)로 요약 | 하루 1회 |

화면이 받는 파일은 `docs/data/*.json`에 있다. 국토부 응답은 `raw/`에 원본 그대로 여섯 달치
보관하고, 실거래 관련 파일은 전부 거기서 다시 만든다.

여기 나오는 거래는 **매물이 아니라 이미 신고된 실거래**다. 계약 후 30일 이내 신고라
최근 거래일수록 나중에 반영된다. 그래서 화면 시세는 두 가지 기준 중 하나로 낸다.

- **신고 기준** — 그 주에 새로 신고된 거래. 지연이 없고 사후에 바뀌지 않는다.
  자치구는 한 주 표본이 얇아 네 주를 겹쳐 센다.
- **계약 기준** — 신고 기한이 지나 마감된 최근 네 주 계약분. 신고 기록이 모자랄 때 쓴다.

어느 쪽으로 냈는지는 화면과 `realestate.json`의 `window.basis`에 적힌다.
추이 그래프는 계약일 기준 주간이다 — 여섯 달을 소급해 그릴 수 있는 쪽이라서다.
신고 기한이 지난 주까지는 실선, 아직 기한이 남아 신고가 덜 들어온 주는 점선으로 잇는다.
점선 구간은 그림에만 쓰고 카드에 적는 값·최고·최저에는 넣지 않는다.

전월세 시세는 **신규 계약만** 센다. 갱신계약은 기존 조건을 잇는 것이라 지금 시세와 다르고,
서울 전월세 신고의 절반가량을 차지한다.

## 개발

```
npm install
npm test
npm run update        # 수집 → 빌드 → 커밋·푸시
```

테스트는 인증키 없이 전부 돈다(외부 API는 스텁 서버로 대신한다).
수집을 직접 돌리려면 `.env`에 인증키가 필요하다.

- `MOLIT_API_KEY` / `MOLIT_API_ENDPOINT` — 아파트 매매 실거래
- `MOLIT_RENT_API_KEY` / `MOLIT_RENT_API_ENDPOINT` — 아파트 전월세 실거래
- `FSS_FINLIFE_API_KEY` — 금융상품 공시

AI 요약은 로컬에 Ollama가 있어야 한다(`OLLAMA_THINK=false` 필요).
